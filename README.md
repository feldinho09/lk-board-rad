# Rad Command Center

Persönliches Center für die Live-Kommentierung von Radrennen: Fahrerprofile, Renn- und Etappenwissen, Statistiken, Geschichten, Hintergründe, Notizen und Zitate – mit LIVE-Ansicht, PDF-Export und Sicherung. Läuft im Browser, auch ohne Internet.

**Adresse:** https://feldinho09.github.io/lk-board-rad/

- Startliste und Fahrerinfos: auf ProCyclingStats Seite öffnen (PCS-Knopf), Strg A, Strg C, im Center einfügen.
- Tipp: In Chrome Rechtsklick auf einen PCS-Knopf → „Link in Split View öffnen“ – dann liegt PCS mit deiner Anmeldung direkt neben dem Center.
- Formatierung: Text markieren → schwebende Leiste (Fett, Kursiv, Leuchtstifte, Aufzählung, Einzug, ★ = in LIVE nach oben).
- LIVE: Startnummer oder Namen tippen.

Entwicklung: `npm install`, `npm run dev`, Tests `npm test` und `npm run build && npm run e2e`. Aufbau: `docs/ARCHITEKTUR.md`.

Die frühere Version („LK Board Rad“) liegt im Zweig `board-v1`.
